***1. Анализ закупки продукции**

**Основная: bm_StorageOperations**

*Данные:*

-- ID - уникальный код записи (1)

-- DocumentID - уникальный код документа (1)

-- OperationID - уникальный код операции (1)

-- ProductID - уникальный код товара (1)

-- VendorID - уникальный код поставщика (1)

-- StorageID - уникальный код склада (1)

-- Amount - сумма закупки (1000.000)

-- Price - цена (1000.000)

-- DateAdd - дата операции (2020-11-15 14:15:30.183)

*Связанные:*

-- product - что купили

-- vendors - продавец

***2. Анализ продажи товара***

**Заголовки: journal**

*Данные:*

-- id - уникальный код чека (1)

-- dater - дата и время продажи (2020-11-15 14:15:30.183)

-- amount - итоговая сумма чека (100.000)

-- loginid - ID кассира (1)

-- transtype - тип операции (301)

**Строки: bm_Journal_Details**

*Данные:*

-- ID - уникальный код строки (1)

-- SourceID - ID заголовка чека (1)

-- ProductID - уникальный код товара (1)

-- Quantity - количество (1000.000)

-- Price - цена продажи (1000.000)

-- Amount - сумма по строке (10000.000)

**Связанные:**

-- product - что продали

-- transtype - типы операций

-- recipe - рецепты


***3. Анализ взаимоотношений с поставщиками***

**Основная: vendors**

-- id - уникальный код (1)

-- firstname - название контрагента (Светофор)

-- INN - реквизиты (3840001848)

**Связанные:**

-- vendorgroup - группа продавца

-- bm_StorageOperations - подсчет сумм закупок

***4. Анализ работы персонала***

**Основная: personnel**

-- personid - уникальный код сотрудника (1)

-- lastname, firstname, middlename - ФИО (Безик Татьяна Сергеевна)

-- flagpos, flagsales - права доступа (1/0)

**Связанные:**

-- journal - чеки

-- bm_JournalSessions - смены

***5. Анализ остатков***

**Основная: stockperiod**

-- id - уникальный код записи (1)

-- productid - ID товара (1)

-- storeid - ID склада (1)

-- quantityopen - остаток на начало (0.000)

-- quantityin - приход (10000.000)

-- quantityout - расход (14999.000)

-- quantityclose - остаток на конец (0.000)

-- datebeginperiod, datefinish - рамки периода (2015-02-17 08:20:36.540)

**Связанные:**

-- product - текущий остаток
